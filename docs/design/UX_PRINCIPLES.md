# UX and Human Factors Principles

## 1. Reduce Cognitive Load

Use a small set of stable concepts. Prefer recognition over recall. A unified command/search model should reduce the need to remember subsystem boundaries.

## 2. Reduce Physical Effort

Consider reachability, pointer travel, keyboard reach, target size, repeated actions, and action frequency.

## 3. Make State Visible

At all times the user should be able to determine:

- what is active;
- where they are;
- what changed;
- what will happen next;
- whether an action succeeded.

## 4. Preserve Direct Manipulation

Newer user intent should supersede stale transitions and background tasks whenever safe.

## 5. Consistency Without Uniformity

Similar tasks should share interaction semantics. Visual presentation can vary by context, density, material, or profile while preserving the same underlying meaning.

## 6. Progressive Disclosure

Expose common controls first. Reveal deeper customization through settings, advanced surfaces, profiles, or explicit expert modes.

## 7. Contextual Information Density

Different workflows may need different densities. Developers, researchers, touch users, and casual users should be able to select coherent density profiles instead of receiving dozens of unrelated density switches.

## 8. Accessibility Is a Design Input

Keyboard navigation, focus visibility, text scaling, contrast, reduced motion, target size, and screen-reader semantics belong in the initial design.

## 9. Error Recovery

Actions should be reversible when practical. Customization failures should preserve the last valid state and allow safe reset/recovery.

## 10. Measure UX Claims

UX hypotheses should have measurable outcomes such as interaction latency, task completion time, error rate, search time, correction count, or local usability observation.
